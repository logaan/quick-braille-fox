# Q: where do practice sentences come from?

The tutor asks the user to type sentences, but a sentence is only fair practice if every character/contraction in it is one the user has learnt or is currently learning.

**Assumption I'm proceeding with:** a built-in corpus of simple words and sentences, filtered at runtime so each drill only uses skills that are learnt or in the active-5 set. Early on (only a few letters known) the "sentences" degrade gracefully to single letters and short letter sequences, growing into real words and sentences as more skills unlock.

Would you rather have generated pseudo-text (random sequences of known skills) instead of a curated corpus, or some mix?
