# Q: what order should grade 2 contractions be taught in?

Grade 2 has ~180 contractions and the order they're introduced matters pedagogically.

**Assumption I'm proceeding with:** the conventional UEB teaching order — alphabetic wordsigns (but, can, do…) → strong contractions (and, for, of, the, with) → strong wordsigns/groupsigns (ch, sh, th, wh, ou, st, ing…) → lower signs (ea, be, con, dis, en, in…) → initial-letter groupsigns (dots 5, 45, 456 words) → final-letter groupsigns → shortforms (abbreviated words like "abv" for above).

Any preference for a different order, or a subset to start with?
