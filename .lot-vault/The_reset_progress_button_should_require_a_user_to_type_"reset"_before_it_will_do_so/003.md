"reset" to confirm.` The Erase button is disabled until the word is typed

matches, Escape cancels. The field autofocuses when the confirm step opens,
and the typed word is cleared whenever the step is cancelled or reopened.

**One thing worth knowing**

While committing, `git add -A` picked up the worktree's `node_modules`
symlink because `.gitignore` had `node_modules/` (directory-only, so a
symlink slipped past). Merging that symlink into `main` replaced the main
checkout's real `node_modules` directory and destroyed it. I unwound the
merge, dropped the symlink from the commit, reran `npm install` to restore
the directory, and reran `./scripts/copy-braille-tables.sh`. The fix is in
the commit: `.gitignore` now has `node_modules` without the trailing slash
so worktree symlinks are ignored too. No source files were affected, and
main is clean.
