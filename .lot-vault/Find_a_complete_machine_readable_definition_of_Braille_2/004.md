Found it. macOS VoiceOver's braille translation is powered by **liblouis**, and the machine-readable Grade 2 definition it uses is the Unified English Braille Grade 2 table bundled with the OS at:

    /System/Library/ScreenReader/BrailleTables/LiblouisBrailleTranslator.brailletable/Contents/Resources/liblouis/tables/en-ueb-g2.ctb

That entry table pulls in more files via `include` directives (grade 1 table, char defs, math, braille patterns, etc.), so a single-file copy would be incomplete.

Delivered, now merged into `main`:

- `scripts/copy-braille-tables.sh` — copies `en-ueb-g2.ctb` plus everything it transitively includes into `data/`. Ran it in the main checkout: 9 files copied, entry point `data/en-ueb-g2.ctb`, ~453 word/contraction rules (e.g. `shall` → dots 146).
- `.gitignore` — ignores `data/` (and `.claude/worktrees/`) so the Apple-shipped tables stay out of git history.
- `CLAUDE.md` — documents the worktree workflow: commit on the worktree branch, merge into main from the main checkout, rerun gitignored-output scripts, then delete the branch and worktree.

The worktree branch has been merged (fast-forward to 6b16952) and the worktree removed. No git remote exists, so everything is local.

Note for the typing tutor: the liblouis table format is line-based and easy to parse — opcodes like `word about 1-12`, `contraction b`, `begword`, `always` followed by dot patterns. The full opcode reference is in the liblouis manual.
