Found the cause. A correct answer only scores if the hint was never shown
(`keystroke` in src/core/session.ts awards CORRECT_BONUS only when
`!p.hintShown`), but for an unlearnt skill the hint auto-shows after
`400 + 300 x score` ms - 400ms at score 0, which elapses while you are still
reading the prompt. So the hint effectively always appears, the bonus never
fires, scores stay at 0 forever, and the hint delay (which grows with score)
never gets longer. The learning loop deadlocks at score 0.

Fix I am making: a correct completion always raises the target skill's score -
+2 (CORRECT_BONUS) when typed before the hint, +1 (new HINTED_BONUS) when the
hint was showing. Answering before the hint stays twice as fast a way to
learn, and the two-mistake penalty (-1) still offsets hinted progress on a
struggling skill. Updating tests and ARCHITECTURE.md to match.
