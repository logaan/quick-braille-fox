Fixed, merged to main (merge 540ba00, fix 86a9196).

Scores now always rise when you correctly type a prompt: +2 if you answered
before the hint appeared, +1 (new HINTED_BONUS) if the hint was showing.
Previously a hinted correct answer scored nothing, and since the hint
auto-shows 400ms after a fresh prompt (at score 0), scores were stuck at 0
forever - no skill could ever be learnt.

With the fix the loop works as designed: hinted answers still make (slower)
progress, each point lengthens the auto-hint delay (400 + 300 x score ms),
giving you more room to recall unaided, and unaided answers learn a skill in
6 correct prompts vs 11 hinted ones. The two-mistakes-in-a-row penalty (-1)
still applies, so a skill you keep fumbling nets no progress.

Verified: all 185 tests pass (2 scoring tests updated, e.g. hinted completion
now expects +1), typecheck clean, and an end-to-end store simulation of the
previously-deadlocked flow (hint fires, then type correctly, 20 prompts)
shows scores climbing off zero. ARCHITECTURE.md's game-rules section updated.
