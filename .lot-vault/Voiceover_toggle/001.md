# Voiceover toggle

If a user is typing using voicover and a braille keyboard then their input will be buffered by that system and will come to qbf one word at a time (normally).

I would like to be able to toggle on and off Voiceover mode.

If voiceover mode is toggled off then the user will type using fdsajkl; to represent cells 12374568 respectively. qbf should to the chording detection needed to translate their inputs into braille cells (eg: fjk would translate to the cell 145) and then on to the actual input (cell 145 when typed as part of a word would be d).

This is a significant piece of work because the meaning of a cell depends on the cells around it. You should act as the coodinator of this work and have subagents plan, implement, and verify it.
