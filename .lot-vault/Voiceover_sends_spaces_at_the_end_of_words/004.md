Done — merged to main as commit 82b2a53 ("Tolerate VoiceOver's trailing spaces in the drill input").

The input handler (`TutorStore.handleInput` in `src/state/store.ts`) now normalizes the input value before matching: trailing spaces are stripped whenever doing so turns a non-matching value back into a prefix of (or all of) the expected prompt text. This handles all three ways the VoiceOver artifact showed up:

- The final word of a prompt committed as "word " now completes the prompt instead of registering a mistake.
- A stray space arriving as its own event after the prompt advanced is ignored on the fresh prompt.
- A qbf run is no longer instantly failed by the trailing space, and a stripped stray space doesn't count as a qbf cell.

Spaces the prompt actually expects (between words) and genuine mistakes that happen to end in a space pass through unchanged. Six new tests cover these cases; all 246 tests and typecheck pass on main. The worktree and branch were merged and removed per the repo workflow.
