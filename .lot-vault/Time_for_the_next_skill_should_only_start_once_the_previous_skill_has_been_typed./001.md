# Time for the next skill should only start once the previous skill has been typed.

At the moment it seems that the countdown for the second skill in a word starts counting down as soon as the timer for the previous skill in a word has completed. This behaviour is incorrect. I could go and get a cup of tea, take 10 minutes to type the first skill in a word, but as long as I type the second skill in under its time limit I should still be scoring two points.

The same goes for spaces between words. The first skill in a new word won't start its timer until the space before the word has been typed.
