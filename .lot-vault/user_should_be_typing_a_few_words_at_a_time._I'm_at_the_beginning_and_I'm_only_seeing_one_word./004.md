Fixed: prompts now show a few words at a time from the very first prompt.

Cause: sequence length was `1 + floor(learntSkills / 15)` words with a uniform
1..max draw, so at the beginning every prompt was exactly one word, and even
with progress single-word prompts stayed common.

Change (src/core/prompts.ts): sequence length is now drawn uniformly from
3..max, where max starts at 3 and grows by one word per 15 learnt skills up to
5. First prompts in a fresh session now look like "cad add bee" / "ace add dad"
instead of "bad". Added a regression test (fresh-window prompts have >= 3
words) and updated docs/ARCHITECTURE.md.

All 74 tests pass and typecheck is clean. Merged to main as 88fdd14 (merge
commit c9f66f4); worktree and branch removed.
